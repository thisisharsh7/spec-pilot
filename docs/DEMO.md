# SpecPilot — 90-second demo script

Setup before recording: dev server on `http://localhost:3000`, real collector data
active (`/sources` shows OpenAI **Healthy**), browser at 1440×900, `/sources` and
`/catalog` open in background tabs.

---

### 0:00 — 0:12 · The problem (landing page)

> "Picking an AI model means reading six pricing pages and guessing. SpecPilot
> answers one question: what's the cheapest model that can *actually* do my job?"

Scroll the hero. Point at the provider strip: **OpenAI**, and **Anthropic — coming
soon**, which we label honestly rather than implying support.

### 0:12 — 0:35 · Describe the task (`/spec`)

Click **Find my model**.

> "Six steps. No model names anywhere — you describe the job."

Type the invoice-extraction task. Move fast; the fields are pre-placeholdered.

- Step 2: tick **Images**
- Step 3: **Structured JSON**
- Step 4: 2,000 requests/day · 1,500 in · 400 out · **400,000 max context**
- Step 5: image input and structured output **mandatory**

> "Selecting an input type *becomes* a hard requirement. Nothing is asked twice."

### 0:35 — 0:45 · The specification (review step)

> "Your answers compile into a machine-checkable spec — with expected failure cases
> and acceptance tests generated by fixed rules, not by a model."

Click **Copy as Markdown**.

> "Copy or download it. It's never stored on a server."

### 0:45 — 1:15 · The recommendation (`/result`)

Click **Find my model**.

**GPT-4.1 nano — $18.60/month.**

> "The cheapest model that satisfies *every* mandatory requirement. Cost decides
> first, always."

Point at the cost table: **60,000 requests → 90M input + 24M output tokens → $9.00 + $9.60.**

> "Every number is shown. No blended averages."

Point at **Pricing caveats**:

> "This page documents no context tier, so we say the estimate *assumes* the listed
> rate applies. It's marked *Assumed*, not *Met* — and the fit panel says one
> criterion rests on an assumption."

Scroll to **Cannot estimate**:

> "The three GPT-5.6 models have a documented `>272K` price tier. Our workload is
> 400K. Rather than quote the cheap tier, SpecPilot refuses to estimate — and tells
> you exactly why."

Scroll to **Rejected**: GPT-4o mini, context 128,000 < 400,000.

### 1:15 — 1:30 · Where the data comes from (`/sources`, `/catalog`)

Switch to **`/sources`**.

> "This is real data. A Bright Data Scraper Studio collector reads OpenAI's own
> model pages — five records, five valid, healthy. Anthropic has no collector, so
> we say *Not configured* rather than faking it."

Switch to **`/catalog`**.

> "Every price links back to the page it came from. And look at *Document input* —
> **Unknown**, not *Unsupported*. The documentation doesn't say, so we don't claim.
> That distinction is the whole product."

## If you have 30 extra seconds

**Self-healing.** A `scraper heal` proposed capturing the Modalities table. Review
caught a real semantic bug — `Image / "Input only"` mapped output to `null` when the
page explicitly says *not supported*. We rejected it, corrected the prompt, and the
second proposal got it right. It sits as an approved draft; it is **not** in
production, and the README says so.

## Do not claim

- ❌ that Anthropic works
- ❌ that `modality_support` is live in production
- ❌ that any model was benchmarked — "requirement fit" is spec match, not accuracy
